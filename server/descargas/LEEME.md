# APK para descarga sin internet

Copia aquí el archivo `RedEmergencia.apk` antes del evento. El servidor lo ofrece en
`http://<ip-del-servidor>:8080/descargar` para que los teléfonos conectados al Wi‑Fi del
puesto de mando instalen la app sin internet.

Formas de obtenerlo:
- Descargarlo de la release `apk-latest` en GitHub (se compila automáticamente).
- Compilarlo localmente (ver `app/README.md`) y copiar
  `app/android/app/build/outputs/apk/debug/app-debug.apk` aquí con el nombre `RedEmergencia.apk`.
